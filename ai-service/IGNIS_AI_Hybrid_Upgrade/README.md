# IGNIS AI — Stage 2 hybrid upgrade

This is a **drop-in add-on**, not a replacement for Stage 1.

## Prerequisites

- Existing `main.py` with `app = FastAPI(...)` and `search_documents(question, top_k=4)` working with PostgreSQL/pgvector.
- Docker PostgreSQL is running on local port **5433**.
- Database tables: `investigations`, `experiments`, `sources`, `measurements`, `document_chunks`.
- ZARM CSV has been imported by your existing `import_zarm.py`.
- Ollama has `llama3.1:8b`, `nomic-embed-text`; Gemma remains intact.

## 1. Copy file

Copy `hybrid_api.py` into `C:\IGNIS_AI\ai-service\` next to `main.py`.

## 2. Dependencies

```powershell
cd C:\IGNIS_AI\ai-service
.\.venv\Scripts\Activate.ps1
pip install "psycopg[binary]" python-dotenv ollama fastapi
```

## 3. Register routes (one-time change)

At the bottom of `main.py`, **after** `search_documents` and after `app = FastAPI(...)`, add:

```python
from hybrid_api import build_hybrid_router
app.include_router(build_hybrid_router(search_documents))
```

Keep all existing routes, model names and source files. Do not replace `main.py`.

## 4. Start API

```powershell
uvicorn main:app --reload --port 8001
```

Open http://127.0.0.1:8001/docs and try:

1. `GET /ai/data/variables` — actual variable names and units.
2. `GET /ai/data/experiments` — experiment records.
3. `POST /ai/ask-hybrid` with:

```json
{
  "question": "Summarize the measured flame propagation rates and identify the experiment sources.",
  "dataset_prefix": "ZARM-",
  "max_experiments": 8,
  "top_k_papers": 4
}
```

If you see no numerical evidence, select `variable_name` using the exact value from `/ai/data/variables`, then repeat.

4. `POST /ai/data/compare` — provide exact experiment codes from `/ai/data/experiments`, plus an exact variable from `/ai/data/variables`.

Example, replacing placeholders:

```json
{
  "variable_name": "REPLACE_WITH_ACTUAL_VARIABLE_NAME",
  "experiment_codes": ["ZARM-REAL_EXPERIMENT_ID_1", "ZARM-REAL_EXPERIMENT_ID_2"]
}
```

## Notes / safeguards

- The **text** RAG queries whatever PDFs are already in Stage 1 (often NASA research).
- Numerical default scope is **ZARM**, which is real external research but **not NASA PSI**. The API labels it explicitly.
- No arbitrary SQL is generated by the LLM. Values are retrieved with parameterized SQL and summarized in Python.
- This is the first hybrid MVP. It does not establish numerical correlations/causation or suppression performance. Scientific datasets with multiple units are not aggregated together.
- API should only be served on localhost until the backend engineer adds authentication and secure network access.
- The retrieved paper passages and their `[Tn]` citations are included in the response; check claims before publication.
